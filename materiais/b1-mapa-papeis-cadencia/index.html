B1
01 · O método

O Conversion Map™ é o sistema de diagnóstico estratégico da Convertfly.

Opera em pilares encadeados — Research → Estratégia (Canvas PDP) → HTMLs → Mensuração → Aprendizado — onde cada etapa entrega um pacote estruturado para a próxima. Nenhuma decisão é achismo.

Tech partner de conversão

Não agência, não dev house. Especialista na página onde a decisão de compra acontece.

O cérebro que aprende

Cada projeto medido vira dado; dado vira padrão; padrão vira peso na Matriz de Decisão.

Reduzir a pessoa-chave

O método segura o conhecimento — a pessoa executa, não é o método. É o que torna a operação escalável.

05 · A regra que não se quebra

Depois do HTML (etapa 7), não vem go-live direto.

O HTML é a estratégia materializada. O Figma aprovado pelo cliente é o que vai pro ar. A etapa 8 — tradução visual da Bia — é gate obrigatório. E o Mauro configura o tracking antes do go-live: sem baseline, não há aprendizado.

Gate 1
Mini-fichas (etapa 6)

Gate anti-TSJ: nenhuma página constrói sem pergunta central e objeção âncora próprias, aprovadas antes do HTML.

Gate 2
Tradução visual (etapa 8)

Nenhuma página avança para o go-live sem o "ok" do cliente no Figma.

06 · Isabella

Você atua entre o OPS e os HTMLs — etapas 6 a 8.

É a zona onde a estratégia (OPS) vira gate aprovado (mini-fichas), depois HTML com design system e ann-tags, e por fim o pacote que a Bia recebe pra traduzir em Figma. É o ponto de maior risco de erro — e onde o método mais protege.

Etapa 6

Mini-fichas — gate anti-TSJ. D+23–24.

Etapa 7

HTMLs — design system + ann-tags. D+24–30.

Etapa 8

Tradução visual — a Bia recebe o pacote. D+30–45.

O detalhe operacional completo de cada etapa está no próximo material — B2, Aprofundamento Etapas 6-8.

07 · O bastão

A regra de ouro de todo Pacote de Handoff

"Um facilitador que nunca viu este cliente conseguiria começar a próxima etapa só com este pacote? Se a resposta é não, falta coisa — não fecha o handoff."

Entre projetos Claude (Research → Canvas → HTMLs), o bastão passa por um bloco copiável, delimitado por ═══ INÍCIO/FIM ═══. Da etapa 8 em diante, o bastão é humano — mas a regra de ouro é a mesma: quem recebe não precisa perguntar nada para começar.
