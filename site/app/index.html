O ponto cego do tema padrão

O template trata todo produto igual.

Um tema de plataforma é feito para servir a qualquer loja — então não serve bem a nenhuma. Todo produto herda a mesma estrutura, a mesma ordem de blocos e o mesmo silêncio diante das dúvidas que travam a compra.

Para fugir disso, o caminho tradicional é contratar agência ou desenvolvedor a cada mudança. Quem não tem verba recorrente para isso simplesmente fica com a página genérica — e a conversão fica onde está. O Convertfly existe para tirar esse pedágio do caminho.

Arquitetura

Quatro compromissos com a integridade da sua loja.

O Convertfly é um SaaS multi-tenant construído headless desde o primeiro dia, com camada de dados isolada por loja. Publicamos como ele se comporta por dentro porque é exatamente aí que um page builder mal feito quebra uma operação.

Compromisso
Como é cumprido
Zero polling

Nenhuma requisição contínua a produtos, categorias ou pedidos durante a navegação do seu cliente. O conteúdo é montado por você no editor e guardado no nosso banco; a vitrine consulta o endpoint /api/render uma única vez por carregamento.

Independência de checkout

Nunca interceptamos um pedido. Os botões de compra gerados pelo app usam a rota nativa da própria plataforma. Checkout, cálculo de frete e processamento de pagamento seguem 100% sob controle da Nuvemshop.

Injeção via Script Tag

O script de renderização é registrado no cadastro do app no Partner Portal e injetado automaticamente na instalação. Nenhuma alteração manual em tema ou código — e nenhuma chamada extra de API no callback de autenticação.

Falhas e reinstalação

O backend usa upsert identificando cada loja pelo seu ID único: desinstalar e reinstalar nunca gera duplicidade nem perda de páginas. Todo o fluxo de autenticação tem tratamento de exceção global — falha vira log interno e você é redirecionado com segurança, sem erro técnico exposto.

Vitrine

Vanilla JS puro

Script leve e assíncrono, sem framework pesado e sem dependência de biblioteca externa. A página é montada a partir de uma árvore em JSON — seção, coluna, componente.

Acesso

OAuth2 oficial, SSO

Autenticação transparente pela própria Nuvemshop. Você nunca cria um login e uma senha separados para usar o app.

Dados

Leitura mínima

A API da plataforma é consultada apenas para dados de apoio — catálogo e categorias. Nada além disso.

Perguntas frequentes

O que os lojistas perguntam antes de instalar.

O app quebra o meu tema?

Não. O script é injetado pela própria plataforma via Script Tag e convive com qualquer tema Nuvemshop, sem alteração manual de código.

Vai deixar a loja mais lenta?

O script é leve, assíncrono e escrito em Vanilla JS, sem framework. São zero requisições contínuas: uma única chamada a /api/render por carregamento de página.

Vocês mexem no meu checkout?

Em nenhum momento. Os botões de compra usam a rota nativa da Nuvemshop; checkout, frete e pagamento continuam inteiramente sob a infraestrutura dela.

Se eu desinstalar, perco as páginas?

Reinstalar não gera duplicidade nem perda: cada loja é identificada por um ID único e o registro é atualizado, não recriado. Enquanto a assinatura estiver ativa, as páginas ficam de pé; se ela terminar, a loja volta ao padrão da plataforma.

Preciso saber programar?

Não. O editor é visual do começo ao fim, e as animações e microinterações são ativadas sem nenhum conhecimento técnico.

Funciona em outras plataformas?

A arquitetura é desacoplada e foi pensada para múltiplas plataformas desde o início. Hoje o app roda em produção na Nuvemshop.
